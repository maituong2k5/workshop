### Week 2 Objectives:

- Understand the fundamentals of computer networking and Amazon VPC.
- Learn about IPv4, CIDR notation and IP address allocation.
- Understand VPC architecture and subnet configuration.
- Learn the differences between Public Subnets and Private Subnets.
- Understand Internet Gateway, NAT Gateway and Route Tables.
- Learn how Security Groups and Network ACLs control network traffic.
- Practice creating and configuring a basic VPC environment on AWS.
