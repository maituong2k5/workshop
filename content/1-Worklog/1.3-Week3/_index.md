## Objectives

- Understand the fundamentals of Amazon EC2 and its role in AWS.
- Learn about EC2 Instance Types and their use cases.
- Understand Amazon Machine Images (AMI) and Amazon EBS.
- Learn about Key Pairs, Security Groups, Elastic IPs and User Data.
- Understand basic Linux commands and file system management.
- Learn how to manage Linux users, groups and permissions.
- Practice connecting to an EC2 instance using SSH.
- Learn how to install and configure Nginx on an Ubuntu server.
