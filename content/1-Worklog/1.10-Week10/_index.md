## Week 10 Objectives:

Learn how to manage AWS resources using AWS Systems Manager, AWS CloudFormation, and AWS CLI. Understand how these tools support infrastructure management, automation, and application deployment.

## Week 10 Achievements:

- Understood the role of AWS Systems Manager in managing AWS resources and EC2 instances.
- Learned about Session Manager and remote instance management.
- Understood how Systems Manager can support the Backend deployment process on EC2.
- Learned the basic concepts of Infrastructure as Code and AWS CloudFormation.
- Understood CloudFormation templates and stacks.
- Gained knowledge of AWS CLI and basic command-line operations.
- Identified the practical role of Systems Manager in the existing TechVina deployment architecture.
